1. INTRODUCTION
======================================================================

Navigation defines how users move between screens within the MBconnect
ecosystem.

The objective is to make navigation intuitive, predictable, and
consistent across every product.

Every user should reach any primary feature in no more than three taps.

======================================================================
2. NAVIGATION PHILOSOPHY
======================================================================

Navigation should be:

Simple

Fast

Consistent

Role Based

Context Aware

Accessible

Responsive

Offline Friendly

19. BEST PRACTICES
======================================================================

✓ Maximum three taps to any primary feature

✓ Keep navigation labels short

✓ Maintain consistent icon placement

✓ Preserve state where appropriate

✓ Use role-based access control

✓ Test navigation on different screen sizes

✓ Avoid dead-end screens
