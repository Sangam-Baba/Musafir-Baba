======================================================================
2. BUSINESS PURPOSE
======================================================================

The OTP Verification module confirms that the person attempting to log
in is the legitimate owner of the registered mobile number.

It is the primary authentication mechanism for MBconnect Version 1.

10. VALIDATION RULES
======================================================================

Only numbers

Required

Exactly 6 digits

Reject spaces

Reject alphabets

Reject special characters

Examples

123456 ✓

987654 ✓

12345 ✕

1234567 ✕

12AB56 ✕

11. API INTEGRATION
======================================================================

Verify OTP

POST

/api/v1/auth/verify-otp

Request

{

"mobile":"9876543210",

"otp":"123456",

"reference_id":"OTP987654"

}

"message":"OTP Verified",

"access_token":"JWT_TOKEN",

"refresh_token":"REFRESH_TOKEN",

"profile_completed":true
