1. INTRODUCTION
======================================================================

Icons and illustrations provide visual communication throughout the
MBconnect ecosystem.

Every icon should immediately communicate its purpose without requiring
users to read supporting text.

Icons should be simple, consistent, and scalable.

======================================================================
2. DESIGN PHILOSOPHY
======================================================================

The icon system follows five principles.

• Simple
• Recognizable
• Minimal
• Consistent
• Scalable

Avoid decorative icons.

Every icon must have a functional purpose.

21. ACCESSIBILITY
======================================================================

Minimum Icon Size

24px

Touch Target

48px

Decorative icons should be hidden from screen readers.

Informative icons must include accessible labels.

Never rely on icons alone to communicate important information.

======================================================================
22. ASSET NAMING CONVENTION
======================================================================

Use lowercase with hyphens.

Examples

icon-wallet.svg

icon-trip-history.svg

vehicle-suv.svg

status-online.svg

illustration-empty-trip.webp

Do not use spaces or special characters.

======================================================================
23. BEST PRACTICES
======================================================================

✓ Use SVG wherever possible

✓ Keep stroke widths consistent

✓ Maintain equal padding

✓ Use semantic colors

✓ Reuse existing icons

✓ Avoid mixing icon styles

✓ Optimize SVG files

✓ Test visibility on light and dark backgrounds
