1. INTRODUCTION
======================================================================

The MBconnect project follows a modular folder architecture.

Every screen has its own:

• HTML
• CSS
• JavaScript

This keeps the project scalable and easy to maintain.

No business logic should be written inside HTML.

Every module must be independent.
