all applications, dashboards, and portals.

Every screen should use colors from this document only.

Developers must never introduce arbitrary colors.

19. ACCESSIBILITY
======================================================================

Minimum Contrast

4.5 : 1

Large Text

3 : 1

Icons

Minimum 24px

Touch Area

48px

Do not rely on color alone to indicate status.

20. BEST PRACTICES
======================================================================

✓ Maintain consistent color usage

✓ Avoid excessive gradients

✓ Limit accent colors

✓ Ensure sufficient contrast

✓ Use semantic colors appropriately

✓ Test in light and dark modes
