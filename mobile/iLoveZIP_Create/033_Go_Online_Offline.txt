======================================================================

Module Name

Go Online / Go Offline

Screen Code

HOME-002

Entry Point

Driver Dashboard

Purpose

Allow drivers to become available or unavailable for receiving trip
requests while ensuring all platform requirements are met.

======================================================================
2. BUSINESS PURPOSE
======================================================================

The Online/Offline engine manages driver availability.

Business Goals

• Receive bookings only when ready

• Prevent illegal trips

• Improve dispatch quality

• Ensure compliance

• Track working hours

9. ONLINE ELIGIBILITY RULES
======================================================================

Driver may go ONLINE only if

✓ Identity Approved

✓ Vehicle Approved

✓ Bank Verified

✓ Background Check Completed

✓ No suspended account

✓ Active vehicle selected

✓ GPS enabled

✓ Background location enabled

✓ Internet connected

✓ No active trip

✓ No expired documents

If any requirement fails

↓

Display blocking reason

↓

Prevent Online

======================================================================
10. OFFLINE RULES
======================================================================

Driver may go OFFLINE

Only when

No active trip

If trip is active

↓

Display

"You cannot go offline during an active trip."

======================================================================
11. BREAK MODE
======================================================================

Driver remains logged in

Trip requests paused

GPS continues

Session timer continues

Break reasons

Lunch

Fuel

Personal

Vehicle Issue

Other

======================================================================
12. AUTO OFFLINE RULES
======================================================================

Automatically set OFFLINE when

No internet > 10 minutes

GPS disabled

Account suspended

Expired mandatory document

Vehicle removed

Logged in from another device

Battery critically low (optional)
