1. INTRODUCTION
======================================================================

Typography is one of the most important elements of the MBconnect
design language.

Every screen must use the same typography system to ensure
consistency, readability and accessibility.

Typography should help users understand information quickly,
especially drivers using the application while travelling.

======================================================================
2. TYPOGRAPHY PHILOSOPHY
======================================================================

The typography system is designed around five principles.

• Readability
• Consistency
• Scalability
• Accessibility
• Simplicity

Large headings should attract attention.

Body text should be easy to scan.

Interactive elements should be clearly distinguishable.

======================================================================

14px

15px

4.5 : 1

Keep line length between 45–75 characters where possible.

======================================================================
21. CSS STANDARDS
======================================================================

Use rem units for scalable typography.

Example

html {
    font-size:16px;
}

h1 {
    font-size:2rem;
}

body {
    font-size:0.875rem;
}

Avoid inline font declarations.
